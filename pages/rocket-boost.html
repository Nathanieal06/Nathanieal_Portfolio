Rocket Boost

Unity 3D C# Unity Physics Engine

Project Overview

"Rocket Boost" is a 3D exploration demo set on a mysterious lost planet. Players control a lander attempting to navigate treacherous terrain to uncover the secrets of a forgotten civilization. This project was specifically built as a foundational Unity exercise, deeply focused on mastering the core gameplay mechanics, physics interactions, and input handling that form the bedrock of game development.

Technical Deep Dive & Game Logic

The core of "Rocket Boost" lies in its reliance on Unity's built-in physics engine rather than kinematically moving the player via Transform translations.

My Contributions

  • Movement Controllers: Implemented custom force-based movement controllers in C# that apply relative torque and thrust vectors to a rigid body, simulating realistic propulsion.
  • Scripting Logic: Scripted robust collision logic and trigger events to handle landing success vs. crash states based on impact velocity.
  • Camera Behaviors: Developed dynamic camera follow behaviors using standard C# logic (pre-Cinemachine) to smoothly track the player without rigid snapping.

Game Mechanics & Physics

  • Rigid-Body Physics: Heavily utilized `Rigidbody.AddRelativeForce` and `Rigidbody.AddRelativeTorque` to decouple the visual rotation from the physics constraints.
  • State Management: Implemented a simple state machine to prevent player input during death sequences or level transition animations.
  • Audio Integration: Linked engine thrust audio pitch and volume to the current input axis, creating responsive auditory feedback for the player.

How It Was Built — Step by Step

01

Core Physics Research

Studied Unity's Rigidbody component and physics engine limitations. Focused on understanding how to apply manual forces to simulate a thruster-based movement system.

02

Lander Movement Scripting

Programmed the C# controller for the lander, utilizing `AddRelativeForce` for propulsion and `AddRelativeTorque` for rotation. Tuned the sensitivity for a challenging but fair handling feel.

03

Collision & Death Logic

Scripted the collision detection system to evaluate impact velocity. Defined safe landing parameters and catastrophic crash conditions with corresponding visual feedback.

04

Environment Design & Obstacles

Designed a series of challenging level layouts with moving obstacles, narrow passages, and fuel pickups. Used a low-poly aesthetic to maintain a clean, focused visual style.

05

Audio & VFX Integration

Implemented dynamic engine thrust audio that scales with input intensity. Added particle systems for thruster flames and explosion effects during crash sequences.

06

Level Flow & Victory Conditions

Scripted the transition logic between levels and final victory screens. Optimized the game loop for instant restarts, encouraging a "one more try" gameplay experience.

What I Accomplished

"Rocket Boost" was pivotal in cementing my understanding of Unity's physics engine. I learned the critical difference between `Update` and `FixedUpdate`, realizing that physics calculations must be synchronized with the physics timestep to prevent jitter and erratic behavior. Mastering these foundational concepts gave me the confidence to tackle much more complex controllers in subsequent projects.
