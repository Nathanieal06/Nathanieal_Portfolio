Zatun Zombie Game

Unity 6 C# URP NavMesh AI Animation Rigging

Project Overview

A high-fidelity third-person zombie survival shooter built entirely from scratch in Unity 6 as a technical test for Zatun. This project was developed to showcase production-ready gameplay programming skills, featuring responsive gunplay, NavMesh-driven enemy AI, procedural animation rigging, a key-based gate progression system, and cinematic narrative sequences—all optimized for high performance.

Technical Deep Dive & Game Logic

To meet the rigorous requirements of a technical developer test, I focused on building highly optimized, scalable systems utilizing modern Unity features.

My Contributions

  • Combat System: Engineered a hybrid hitscan-projectile combat system for 100% reliable hit detection, ensuring responsive gunplay.
  • Shader Development: Authored custom URP-compatible dissolve shaders using SRP Batcher-friendly CBUFFER blocks to handle enemy deaths and VFX.
  • Input & Audio: Integrated the New Input System for robust cross-platform controls, and implemented spatialized 3D zombie audio.

Game Mechanics & Physics

  • IK Animation Rigging: Implemented IK-driven procedural animation rigging for natural weapon aiming, spine bending, and procedural head tracking.
  • Optimized AI Spawner: Developed a throttled NavMesh AI spawner capable of maintaining 60+ FPS while managing multiple active agents, utilizing object pooling.
  • State Management: Engineered the core progression logic, enforcing strict player state management (e.g., dual-key inventory systems, conditional gates).

How It Was Built — Step by Step

01

Project Setup & Scene Design

Configured a new Unity 6 project with URP rendering pipeline, imported key packages (Cinemachine, New Input System, NavMesh), and designed the zombie environment map layout.

02

Player Controller & Combat

Built a third-person player controller with smooth camera follow via Cinemachine. Implemented a hybrid hitscan-projectile gun system for 100% reliable hit detection on any target collider type.

03

Zombie AI & NavMesh Baking

Baked a NavMesh across the entire level, then coded the zombie FSM — Idle → Chase → Attack → Death. Zombies pathfind around obstacles and react to player proximity in real time.

04

IK Animation Rigging & Dissolve Shader

Applied Unity's Animation Rigging package for procedural IK so the player's arms always aim accurately. Authored a custom URP dissolve shader for satisfying enemy death VFX.

05

Progression & Key System

Designed the dual-key inventory system where the player must find a Normal Key to open gates and a Victory Key to trigger the win condition, enforcing strict linear progression.

06

Polish, Audio & Optimization

Added 3D spatialized zombie growls, weapon fire/reload audio, pause menu, options volume sliders, and ran performance profiling to maintain 60+ FPS throughout the entire game.

What I Accomplished

This technical test was a major achievement in independently delivering a polished vertical slice within tight constraints. I learned to seamlessly integrate Cinemachine with custom player physics, resolved complex bugs related to NavMesh initialization crashes during scene loads, and optimized LayerMask-based physics checks to keep the game running smoothly.
