Unity RPG

Unity 3D C# RPG Mechanics In Development

Project Overview

This project is an expansive, story-driven Role-Playing Game built entirely from scratch in Unity. Currently in active development, it serves as a massive technical playground where I implement robust combat systems, dynamic exploration mechanics, and a highly customized character control system. The goal is to create a seamless, immersive RPG experience that pushes the boundaries of standard Unity capabilities.

Technical Deep Dive & Game Logic

Building a modern RPG requires complex interlocking systems. Here is a breakdown of the core logic and my specific contributions to the codebase.

My Contributions

  • Core Architecture: Architected the entire game framework in C#, utilizing clean code principles and event-driven architecture to decouple game systems.
  • Inventory Management: Designed a highly modular and scriptable-object-driven inventory and itemization system.
  • Combat & Damage: Engineered complex state machines for hit detection, combo chains, and damage calculation.

Game Mechanics & Physics

  • State Machine AI: Developed a finite state machine (FSM) for enemy AI, allowing NPCs to seamlessly transition between patrolling, chasing, attacking, and fleeing.
  • Custom Physics Controllers: Implemented a rigid-body based character controller to handle complex terrain navigation, gravity manipulation, and responsive jumping mechanics.
  • Animation Rigging: Integrated Unity's Animator with code-driven blend trees to ensure fluid transitions between combat swings and movement.

How It Was Built — Step by Step

01

Project Setup & Architecture

Set up the Unity project with URP, configured the folder structure, and defined the ScriptableObject-based event system to ensure all game systems would remain loosely coupled from day one.

02

Player Controller & Movement

Built a custom Rigidbody-based character controller from scratch, handling movement, gravity, jump physics, and slope handling — no default Unity Character Controller used.

03

Combat & State Machines

Engineered a finite state machine (FSM) for the combat system covering idle, attack, hit, and death states. Integrated blend trees in the Animator for fluid combat animation transitions.

04

Inventory & Item System

Created a modular, ScriptableObject-driven inventory system. Items, weapons, and consumables are data assets that the player can collect, equip, and use — all managed without hardcoded references.

05

Enemy AI & NavMesh

Implemented NavMesh-based enemy AI with states for patrolling, chasing, attacking, and fleeing. Enemies dynamically react to the player's position and health level in real time.

06

World Building & Ongoing Development

Currently designing the open-world map, quest system, and save/load architecture. Profiling scene performance and iterating on system design for long-term scalability.

What I Accomplished

Developing this RPG has been a masterclass in software architecture. I successfully moved away from monolithic "manager" scripts and implemented an event-bus system that drastically improved performance and maintainability. I learned how to profile memory usage for large open-world scenes and optimize NavMesh generation for complex terrain. Moving forward, I am focusing on expanding the quest logic and saving/loading systems.
