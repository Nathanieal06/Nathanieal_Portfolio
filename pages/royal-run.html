Royal Run

Unity 3D C# Cinemachine Unity Particle System

Project Overview

"Royal Run" is a 3D endless runner game inspired by classics like Temple Run and Subway Surfers. It tests players' reflexes as they navigate an infinite pathway, collecting coins and apples while avoiding obstacles. The core focus of this project was to understand procedural generation and memory management in an endless environment.

Technical Deep Dive & Game Logic

To create an "endless" game, the environment cannot actually stretch to infinity. I had to implement clever procedural generation techniques to create the illusion of an endless world.

My Contributions

  • Procedural Level Generation: Engineered a system that dynamically instantiates and positions terrain "chunks" just ahead of the player to create an infinite track.
  • Player Movement & Controls: Programmed smooth, lane-based WASD controls, allowing for snappy sidestepping, jumping, and sliding mechanics.
  • Camera Tracking: Integrated Unity's Cinemachine via C# scripts to create a dynamic, smooth-following camera that adjusts its FOV based on player speed.

Game Mechanics & Physics

  • Object Pooling: Instead of constantly destroying and creating new terrain chunks (which causes garbage collection spikes), I implemented Object Pooling to recycle environment chunks that fall behind the player.
  • Collision & Triggers: Designed rigid-body collision detection for obstacle impact and trigger volumes for collecting coins and power-ups.
  • Score Management: Built an event-driven UI and score management system that accurately scales score based on distance traveled and items collected.

How It Was Built — Step by Step

01

Core Mechanic Design

Defined the lane-based movement mechanics and obstacle interaction rules. Focused on creating a responsive and intuitive control scheme suitable for an endless runner.

02

Chunk System Implementation

Developed a library of level "chunks" that can be seamlessly connected. Each chunk contains a unique set of obstacles, coins, and environment details.

03

Procedural Generation Logic

Scripted the logic to spawn new chunks ahead of the player while recycling older ones behind. Implemented random selection to ensure each run feels fresh and unpredictable.

04

Player Physics & Animation

Configured the player character's movement physics for sidestepping, jumping, and sliding. Integrated animations with movement speed for a smooth visual experience.

05

Object Pooling Optimization

Implemented an object pooling system for obstacles and collectables. This minimizes the performance cost of frequent instantiation and destruction, ensuring stable FPS.

06

Score & UI Integration

Created a dynamic UI for score tracking, coin collection, and game-over states. Balanced the difficulty curve to increase speed and obstacle density as the player progresses.

What I Accomplished

This project was a major stepping stone in my understanding of memory optimization. Before implementing object pooling, the game would stutter over time. Learning how to manage memory dynamically in C# was a massive accomplishment. I also refined my understanding of Cinemachine, learning how to decouple the camera logic from the player's direct transform hierarchy to prevent jitter.
